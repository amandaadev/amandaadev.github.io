Sobre mim

Meu nome é Amanda Hellen, sou formada em Sistemas de Informação e desenvolvedora em constante evolução, com foco em desenvolvimento de software. Tenho experiência prática adquirida durante meu estágio na área de tecnologia, onde pude atuar com desenvolvimento, aprendizado contínuo e trabalho em equipe. Atualmente, estou dedicada aos estudos e ao aprimoramento técnico, aprofundando meus conhecimentos em desenvolvimento back-end e front-end, construção de APIs, boas práticas de código e projetos pessoais. Busco oportunidades para aplicar minhas habilidades, aprender com novos desafios e crescer profissionalmente na área de tecnologia, sempre com dedicação, consistência e vontade de evoluir.

Aplicação de Vagas de Emprego

Aplicação web para facilitar a busca e publicação de vagas de emprego. Habilidades

HTML, CSS e JavaScript

As famosinhas da web, formam o principal conjunto de tecnologias para qualquer aplicação web. Hoje já consigo entender melhor essas tecnologias, principalmente ando praticando muito mais para aprimorar meus conhecimentos.



React

O React é uma biblioteca JavaScript declarativa, eficiente e flexível para criar interfaces de usuário. Atualmente, estou em constante evolução nos meus estudos de React. Continuo aprimorando minhas habilidades, explorando novos conceitos e pretendo aplicar em projetos práticos. Meu objetivo é dominar ainda mais essa poderosa ferramenta para criar aplicações cada vez mais robustas e eficientes.



Tailwind

Tailwind CSS é um framework de CSS utilitário altamente configurável que permite criar rapidamente interfaces de usuário modernas e responsivas. Ele oferece uma vasta coleção de classes utilitárias que podem ser combinadas para construir qualquer design diretamente no HTML. Estou começando a praticar já em alguns projetos no trabalho e pretendo aplicar em projetos pessoais também.



Node JS

Node.js é um software de código aberto e multiplataforma que utiliza o motor V8 do Google, permitindo a execução de códigos JavaScript fora do ambiente de um navegador web. Com ele é possível construir servidores e aplicações de rede escaláveis, aproveitando sua arquitetura orientada a eventos e não bloqueante. Estou aprofundando meus conhecimentos em Node.js, explorando suas capacidades e pretendo aplicá-las em meus futuros projetos.
